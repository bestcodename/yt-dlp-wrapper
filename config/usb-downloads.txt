# config/usb-downloads.txt
#
# Software to copy onto the USB stick's /software/ folder during `usb:setup`.
# One link per line. Blank lines and lines starting with `#` are ignored.
#
# Supported line types:
#   https://...   or   http://...   — downloaded now via curl and copied onto the stick.
#   magnet:...                      — recognized but NOT downloaded yet (torrent support is
#   urn:btmh:...                      planned, see TODO.md). These lines are safe to add now
#                                      for future use; they are currently just logged and skipped.
#   /a/local/file.exe                — an existing local file: copied onto the stick as-is,
#                                      no download involved.
#   /a/local/directory/               — an existing local directory: every file directly
#                                      inside it (non-recursive) is copied onto the stick.
#   /a/local/directory/**             — same, but scanned recursively (all subfolders too),
#                                      preserving each file's subfolder path under /software/
#                                      on the stick (so same-named files in different
#                                      subfolders don't collide).
#                                      Relative paths resolve against the current working
#                                      directory (i.e. the project root when run via
#                                      `bin/console`).
#
# NOTE: unlike the Debian ISO download, there is no published checksum for downloaded files,
# so they are NOT integrity-verified — only cached by filename/size. usb:setup does reject
# responses with a text/* Content-Type (e.g. login/session-gated HTML pages), so a gated URL
# now fails loudly with a warning instead of silently copying garbage onto the stick.
